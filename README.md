
# 📈 Regra do 72 — Calculadora de Investimentos

Aplicação web educativa que apresenta a Regra do 72 e permite realizar estimativas de crescimento de investimentos com juros compostos.

<p align="center">
  <a href="https://kayki-dasilva.github.io/Regra-do-72/">
    <img src="https://img.shields.io/badge/Acessar%20Projeto-222222?style=for-the-badge&logo=githubpages&logoColor=white">
  </a>
</p>

## ✨ Funcionalidades

- Exemplos práticos de cálculos.
- Estimativa do tempo necessário para dobrar um investimento.
- Cálculo do montante com juros compostos.
- Exibição dos resultados em reais (R$).
